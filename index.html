Live File Link (recommended)

Link this app to a real .sqlite file on your computer. Every save then writes straight to that file — clearing browser data can no longer wipe your data, since it isn't the only copy anymore.

Cloud Sync (Turso) — optional

If you've set up a Turso cloud database, paste its details below. Once saved, Students/Classes/Subjects changes are mirrored to Turso in the background as an extra safety copy — your local file stays the main copy the app runs from, and everything keeps working exactly the same if the internet is down.

Sync Health Check

Compares row counts between your local file and Turso for every mirrored table — catches silent sync failures before they become a real problem.

Restore Local from Turso

Pulls your current Turso data down and replaces whatever is on THIS device with it — use this if your local data is empty or out of date but Turso still has your real data.

Push Local to Turso

Pushes THIS device's current data up and replaces whatever is in Turso with it — use this if local is ahead of Turso (e.g. after retrying a save didn't clear a Sync Health Check mismatch) and you want to force them back in sync.

Academic Year & Active Term

Sets which term teachers can record marks for. Only the Dean of Studies changes this — teachers will only see and save to whichever term is active here.

Security & Roles

This app runs entirely offline in this browser — there is no server. PINs act as a screen lock for shared computers, not a defence against someone editing the file directly.

Teacher PINs are set per teacher on the Teachers tab — each teacher only sees the subject(s) assigned to them there.

Danger Zone — Clear All Data

Permanently deletes every student, mark, class, subject, teacher, commitment, group, and history record. PINs, the active term setting, and your Turso connection details are kept so you aren't locked out afterward. This cannot be undone — make sure you have a recent backup (Backup tab) before doing this.

Promote Students to a New Academic Year

Run this once, at the start of a new academic year. It moves every active student to their next class (or keeps them repeating), archives their old class in the promotion history, and switches the whole app over to the new academic year.
